Да, именно! Чтобы цвет становился темнее с каждым повторным прохождением одного и того же сегмента, можно использовать счётчик повторов и градацию цвета. Вот как это можно реализовать:

---

🧠 Идея

1. Храним сегменты с количеством проходов:struct SegmentInfo {
    QLineF segment;
    int passCount = 1;
};
QVector<SegmentInfo> m_segments;

2. При каждом движении проверяем, пересекается ли новый сегмент с уже существующим:• Если да — увеличиваем `passCount`.
• Если нет — добавляем новый сегмент с `passCount = 1`.

3. Цвет зависит от `passCount` — чем больше, тем темнее.


---

🎨 Генерация цвета

Вот пример функции, которая делает цвет темнее:

QColor getColorForPass(int passCount) {
    int baseR = 60, baseG = 140, baseB = 255;
    int alpha = std::min(255, 60 + passCount * 40); // прозрачность растёт
    int darken = std::min(180, passCount * 30);     // затемнение

    return QColor(
        std::max(0, baseR - darken),
        std::max(0, baseG - darken),
        std::max(0, baseB - darken),
        alpha
    );
}


---

🔁 В `advance(dt)`:

QLineF newSeg(prevP, currP);
bool matched = false;

for (auto& seg : m_segments) {
    if (seg.segment.intersect(newSeg, nullptr) == QLineF::BoundedIntersection) {
        seg.passCount++;
        matched = true;
        break;
    }
}

if (!matched)
    m_segments.push_back({newSeg, 1});


---

🖌️ В `paintEvent`:

for (const auto& seg : m_segments) {
    QPainterPath path;
    path.moveTo(seg.segment.p1());
    path.lineTo(seg.segment.p2());

    QPainterPathStroker stroker;
    stroker.setWidth(2.0 * m_r);
    stroker.setCapStyle(Qt::RoundCap);
    stroker.setJoinStyle(Qt::RoundJoin);

    QPainterPath filled = stroker.createStroke(path);
    p.fillPath(filled, getColorForPass(seg.passCount));
}

🔧 Результат

• Первый проход — ярко-голубой.
• Второй — темнее.
• Третий — ещё темнее.
• И так далее, пока не станет почти чёрным или непрозрачным.
